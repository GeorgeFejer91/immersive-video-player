Connection & playback notes

Both screens load the same film. The remote uses VDO.Ninja signaling and encrypted WebRTC data, with a mutual-proof pairing handshake. Internet is required; camera and microphone access are never requested. Direct peers can learn each other’s network address.

Keep the phone page awake. A timed start and drift correction keep the previews close; buffering and browser scheduling can interrupt synchronization. If the viewer buffers, playback pauses for both screens.
