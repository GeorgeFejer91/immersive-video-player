# Phone controlled immersive video

2026-11-05. User authorized implementation, GitHub push and live Pages publication.

Updated 2026-11-06: the root URL is a shared session launcher with an immediate QR. Its fragment-only invitation opens the viewer on Quest/immersive-capable browsers and compact controls on smartphones; uncertain devices choose a role, and explicit viewer/controller links always override detection. The root downloads no video and constructs no remote connection. The viewer keeps the supplied invitation across recoverable connection failures, rather than generating a different room. End/expiry clear keys and role links locally. A copied bearer can open a separate viewer; a fresh viewing pair should generate a new QR.

The visible interface is limited to Immersive Video Player, a QR and functional controls/status. Install app is visible on entry until real playback starts; its dialog contains platform-specific browser installation instructions. Viewer Connection, Playback and View use native exclusive details groups. The phone is a full-window native video player with Start/Pause/Stop, a time slider and an SVG headset button opening a connection dialog. The dialog closes on authenticated ready. Phone uses the bundled asset directly, with no WebGL renderer or peer video track. Header/footer anchor a stretch body; width and height drive spacing/control/type tokens. Pinned Pretext measures actual labels; unfittable enlarged text uses readable document flow. Dialogs have their own scroll policy.

The viewer and phone select Enable then Connect. The user selects VR with a headset gesture; only video appears in the immersive session. The first viewer remains authoritative; each invited phone independently requests transport scope. The host serializes accepted controls and broadcasts the shared timeline. Stop pauses and resets every connected player, separately from Disconnect. Phone departure preserves other connections. Join viewer adds a follower with the same state. Interrupted connections retry with bounded backoff while visible/online; fresh state and clock restore control. Explicit Disconnect and 30-minute expiry stop recovery.

Reuse the BRSP/1 core and pinned VDO.Ninja 1.5.5 adapter. Only data crosses WebRTC: both devices fetch the same bundled MP4 over HTTPS. Bounded clock samples and a 500 ms future play anchor coordinate the players. Green pulse requires authenticated ready, a real returned viewer state younger than two seconds, clock sampling, ready/non-seeking local video, matching playing/paused state and position within 350 ms of the authoritative anchor. Other states are red with a matching accessible name. Reduced motion disables the pulse. This is state/preview agreement, not proof of hardware frame lock. Command errors remain visible on the phone player; a rejected viewer play publishes a paused timeline.

Projection defaults to Kodak circular fisheye for the square Jona source, with adjustable lens angle, yaw/pitch, view FOV, equirectangular 180/360 and flat alternatives. A sphere shader maps viewing rays to the circular source independently for each eye (the source is mono).

Static Vite build with relative paths, Three.js WebXR, QR generation and actual Pretext measurement. A subpath-safe manifest opens standalone phone controls. The generated service worker caches an explicit, versioned static UI allow-list, never media/ranges, APKs, query URLs, invitation material or credentials. Updates activate naturally after old clients close. No backend, camera/microphone capture, tracking, arbitrary remote URLs or native bridge. Per-peer budgets and a bounded host queue, 250 ms state heartbeat, 2 second stale threshold and acknowledgements limit work. Internet is required for media and VDO signaling/ICE; same Wi-Fi is optional. Browser tests do not qualify physical Quest/iOS/Android suspension or guarantee service availability.

Publish only this curated browser repository and the specifically authorized full-length Jona web encode. Retain library licenses and hashes. Older native work stays in the original workspace.
